# FlipPanel

[English version](README.md)

Аддон для аукциона **WoW Forever** (`Interface: 16001`): быстрый флип одного ресурса.
Задаёшь предмет, максимальную цену и количество и покупаешь одной кнопкой или Ctrl + колесо мыши. Поиск не нужен.

Работает только с ресурсами, то есть с товарами, которые продаются по количеству: ткань, руда, слитки, травы.

## Возможности

- Покупает ровно N штук, если средняя цена не выше твоего максимума. Дороже максимума не купит.
- Одна кнопка (или Ctrl + колесо). Каждое нажатие — ровно один запрос: узнать цену, подтвердить или отменить.
- Выставляет выбранное количество по отдельной цене продажи на выбранный срок.
- Список до 10 последних предметов, у каждого своя цена покупки, цена продажи и количество.
- Кнопки количества 5 / 10 / 20 / 50, звуки, статистика трат за сессию.
- Окно лога: покупки и выставления на одной вкладке, ошибки и отмены на другой. Лог сохраняется между сессиями.

## Установка

Скопируй папку `FlipPanel` в `Interface/AddOns` клиента WoW Forever и перезапусти игру.
Или поставь через WowUp: Get Addons → Install from URL → вставь ссылку на этот репозиторий.

## Использование

Панель появляется справа от окна аукциона. В ней три блока сверху вниз: «Предмет», «Продажа» и «Покупка».
Внизу — звуки, кнопка лога и статистика сессии.

1. «Предмет»: перетащи предмет в слот, введи ID и нажми Enter или сделай Shift+клик по ссылке, пока курсор в поле ID.
2. «Продажа»: задай цену за штуку (`3s`, `55c`, `1g20s`), количество и срок, жми «Выставить».
3. «Покупка»: задай макс. цену за штуку и количество, жми кнопку покупки или крути Ctrl + колесо.
   Надпись на кнопке говорит, что сделает следующее нажатие:
   - «Купить» — узнать цену на N штук;
   - «ПОДТВЕРДИТЬ» — цена подходит, нажатие покупает;
   - «ОТМЕНИТЬ котировку» — цена не подошла (дорого, не хватает золота, столько нет в продаже), нажатие отменяет.
4. Если сервер не ответил (кнопка зависла на «Жду ответ сервера»), через 3 секунды жми ту же кнопку ещё раз:
   она сбросит панель. Если кто-то выкупил товар раньше твоего «ПОДТВЕРДИТЬ», покупка не пройдёт с ошибкой
   аукциона, и панель сама вернётся к «Купить»: следующее нажатие запросит новую цену.

Язык интерфейса — как у клиента игры: на русском клиенте русский, на любом другом английский.

Команды: `/flip` показать/скрыть, `/flip log` окно лога, `/flip debug` писать каждый запрос к аукциону и ответ во вкладку лога «Отладка» (кнопка «Копировать» там даёт скопировать текст), `/flip wheel` вкл/выкл Ctrl + колесо,
`/flip reset` сбросить статистику, `/flip resetpos` вернуть панель на место.

## Как это устроено

- Только игровой Lua API (`C_AuctionHouse`), без внешних программ.
- Одно действие — одно нажатие. Таймеров нет, сам аддон ничего не отправляет: запрос цены, покупка, отмена
  котировки и выставление уходят только по твоему нажатию, по одному запросу на нажатие.
- Аддон не сканирует аукцион и соблюдает серверный лимит запросов.
